# Louie-crew-portfolio

Interactive portfolio **v2** for Louie Tayad (Loragine) — charcoal + gold theme with **BUDDY**, a cursor-following mascot.

**Live site:** https://freelanceloes-max.github.io/Louie-crew-portfolio/

**Classic portfolio (v1, unchanged):** https://freelanceloes-max.github.io/va-systems-portfolio/

## Local preview

```bash
python3 -m http.server 8080
# open http://localhost:8080
```
